### Not implemented — client actions, not code fixes

- **Rate limiting** (part of item 18): no per-IP rate limit on `/api/checkout` or `/api/android-interest`. Serverless in-memory counters don't work across Vercel instances — doing this properly needs either Vercel's own Firewall rate-limit rules (dashboard config, no code) or a shared store like Upstash Redis (new service/dependency). Recommend the Vercel Firewall route first since it needs no new account.
- **Cloudflare Turnstile** (part of item 18): honeypot + time-trap now cover the common case; Turnstile is a further layer the skill recommends but needs the user to create a free Cloudflare account and get site/secret keys — not something to add without being asked, since it also changes the signup UX.
